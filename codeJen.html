Your script — makeGithubgreen.sh

Save it inside your repository, then run: bash makeGithubgreen.sh — afterwards git push origin main (or enable auto-push above).

Make sure it actually turns green

  • Run the script inside an existing git repo — git init plus a remote (git remote add origin <url>).
  • The commit email must be added to your GitHub account: Settings → Emails.
  • Commits must land on the default branch and must be pushed — local commits alone don't count.
  • The repo must be public, or enable “include private contributions” on your profile.
  • The script needs GNU date (Linux, WSL, Git Bash on Windows). On macOS: brew install coreutils and use gdate.
