How to use

  • Step 1: Download rewrite_history.py into your repo folder.
  • Step 2: Run: python rewrite_history.py (python3 on some Mac/Linux systems).
  • Step 3: The script rewrites all commit dates, then force pushes.
  • Step 4: Check your GitHub profile — squares update within minutes.
  • Requires Python 3.6+ and git installed. Commit or stash your changes before running.
  • Changed your mind before pushing? git reset --hard refs/original/refs/heads/main restores the old history.
